name: App-wide typography direction
description: User chose Inter for the entire Waste2Worth AI interface, not only Home.
---

Use Inter consistently throughout Waste2Worth AI, including Scan, Offer, Market, Reports, Profile, navigation, headings, buttons, cards, forms, and labels. Do not reintroduce serif typography.

**Why:** The user explicitly expanded the earlier Home-only font direction to make the entire app consistent.

**How to apply:** Preserve this app-wide typeface in future UI work unless the user requests another direction. Typography-only changes must not change layout, colors, wording, or functionality.
